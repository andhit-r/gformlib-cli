gformlib-cli Documentation
===========================

**gformlib-cli** is the official command-line interface for
`gformlib <https://gformlib.readthedocs.io>`_ – manage Google Forms directly
from your terminal.

.. code-block:: console

   $ gformcli form create form.json --service-account sa.json
   ✓ Form created successfully.
   ╭─ Customer Survey ──────────────────────────────────────────────╮
   │ Form ID       abc123                                           │
   │ Responder URI https://docs.google.com/forms/d/abc123/viewform  │
   ╰────────────────────────────────────────────────────────────────╯
